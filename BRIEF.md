# ACTS Computer College — simple modern one-page site (brief)

Build a single static page: `index.html` + `styles.css` (+ tiny `script.js` only if needed for mobile nav).
No frameworks, no build step, no Tailwind CDN. Must work on GitHub Pages (relative paths only).
Images already in `assets/`: logo.webp (round seal), logo-yellow.webp (wordmark on yellow), school.webp (campus building), cover-shs.png, cover-programs.png, president.avif.

## Brand
- Forest green `#0B5E3A` (primary), deep `#06371F`, warm yellow `#F2E21B` (accent, use sparingly), off-white paper `#F7F6F0`, ink `#14201A`.
- Display font: "Fraunces" or "Instrument Serif"; body: "Instrument Sans" (Google Fonts). Founded 1987, Santa Cruz, Laguna, Christian culture.
- Tone: calm, confident, editorial. No glassmorphism, no gradient blobs, no emoji, no fake stats, no generic icon-card grids with identical rounded boxes.
